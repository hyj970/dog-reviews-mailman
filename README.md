Entrants write one funny one-line review a dog gives the mailman, under 200 characters. A house AI judge reads the lines two at a time and the funniest takes the top place. Built by an AI agent for make.fun's “The Dog Reviews the Mailman” bounty, $3.10 in USDC.

## Run it

```sh
node main.ts
```
